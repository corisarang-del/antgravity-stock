# 2026-03-13 UI/UX 복원 및 드롭다운 최종 수정

2026-03-13

## 해결하고자 한 문제

이전 세션에서 git stash가 `git filter-branch` + `git gc --prune` 실행으로 파괴되어 UI/UX 수정 내용이 전부 유실됨.
유실된 항목:
1. 다크모드 CSS 변수 블록 (`index.css`)
2. ThemeProvider 래핑 (`App.tsx`)
3. `"/"` → Diagnose 랜딩, `"/home"` → Index 대시보드 라우팅 변경
4. AppShell 개선 (로고 폰트, 탭 간격, 다크모드 토글)
5. Index.tsx 대시보드 단순화 (StockList/MarketOverview 제거)
6. 검색 드롭다운이 분석 결과 카드를 가리는 문제 (z-index + 배경색)
7. 드롭다운 재출현 버그 (suggestion chip 클릭 후 useEffect가 dropdown 재활성화)

## 변경 파일

### `src/App.tsx`
- `ThemeProvider` (`next-themes`) 로 전체 앱 래핑
- `attribute="class"`, `defaultTheme="light"`, `enableSystem` 설정
- 라우트 재정의: `"/"` → `<Diagnose />`, `"/home"` → `<Index />`

### `src/index.css`
- Google Fonts에 `Playfair Display:ital,wght@0,700;1,700` 추가
- `.dark {}` CSS 변수 블록 추가 (다크모드 전체 팔레트)
- `.font-logo { font-family: 'Playfair Display', serif; }` 추가

### `src/components/AppShell.tsx`
- 로고 텍스트에 `font-logo italic` 클래스 적용 (세리프 이탤릭)
- 탭 경로 변경: `/home` (기존 `/`)
- `isActive()` 단순화: `location.pathname.startsWith(path)`
- 탭 간격: `gap-1` → `gap-2`, 비활성 탭에 `hover:bg-background/50` 추가
- 다크모드 토글 버튼 추가 (헤더 우측, Sun/Moon 아이콘)
- 모바일 홈 탭 아이콘 분기: `path === "/home"` 조건 수정

### `src/components/MarketOverview.tsx`
- 티커 React key 경고 수정: `key={i}` → `key={\`${idx.name}-${i}\`}`

### `src/components/StockList.tsx`
- 검색 input에 `id="stock-search"` + `<label htmlFor>` + `aria-label` 추가 (a11y)

### `src/components/StockDiagnose.tsx`
- 드롭다운 클래스: `glass z-50` → `bg-card z-[100] shadow-lg`

### `src/pages/Diagnose.tsx`
- `AppShell`로 래핑 (기존 standalone 헤더/티커 제거)
- **핵심 수정**: `skipDropRef = useRef(false)` 패턴으로 드롭다운 재출현 버그 수정
  - `diagnose()` 호출 시 `skipDropRef.current = true` 설정
  - `useEffect([query])` 진입 시 `skipDropRef.current`가 `true`면 즉시 dropdown 닫고 return
  - 원인: `setQuery(stock.name)` → `useEffect` → `setShowDrop(true)` 순으로 실행되어 드롭다운 재활성화
- 드롭다운 클래스: `glass z-50` → `bg-card z-[100] shadow-lg`
- CTA 이동: `navigate("/stock/...")` → `navigate("/home", { state: { symbol } })`

### `src/pages/Index.tsx`
- 전면 재설계: StockList, MarketOverview, 사이드바 레이아웃 제거
- `useLocation` → `location.state?.symbol` 읽어서 selectedSymbol 초기화
- AI 진단 배너: `navigate("/")` 로 Diagnose 페이지 이동
- 구성: AI 진단 배너 → StockHeader → 차트(1M/2M/3M) → AI 분석 패널

### `src/pages/Portfolio.tsx`
- "마켓" 링크: `to="/"` → `to="/home"`

### `src/pages/Upgrade.tsx`
- 하드코딩 색상: `text-white` → `text-loss-foreground`
