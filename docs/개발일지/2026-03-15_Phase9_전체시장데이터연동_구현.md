## 해결하고자 한 문제

Pro 대시보드가 14개 하드코딩 종목만 보여주는 상태에서 한국 전체(~2,400개) + 미국 전체(~5,500개) 종목 조회 및 스크리닝 기능 구현.

제약: 무료 API만 사용, GitHub Actions 월 2,000분, Supabase 500 MB 이내.

---

## 해결된 것

### 백엔드 데이터 수집 (Phase 9-A)

**backend/requirements.txt**
- `pykrx>=0.2.0`, `opendartreader>=1.0.0` 추가

**supabase/migrations/20260315000001_market_universe.sql**
- `ticker_universe (symbol, market, name, sector, industry, updated_at)` — 종목 메타
- `market_snapshot (symbol, market, close, change_pct, market_cap, per, pbr, volume, snapshot_date)` — 일별 스냅샷
- 성능 인덱스 3개 + RLS (service_role only)

**backend/services/market_snapshot_service.py** (기존 클래스 유지 + 신규 함수 추가)
- `collect_ticker_universe_kr()`: PyKRX로 KOSPI(.KS) + KOSDAQ(.KQ) 전체 종목명 수집
  - 기존 설계에서 OpenDartReader 대신 PyKRX 사용으로 변경 (KOSPI/KOSDAQ 구분 가능)
- `collect_ticker_universe_us()`: SEC EDGAR `company_tickers.json` — 미국 전체 티커
- `collect_kr_snapshot(date_str)`: PyKRX 벌크 OHLCV + 재무지표
- `collect_us_snapshot()`: yfinance.download 1,000개씩 배치
- `_cleanup_old_snapshots()`: 3일 초과 행 삭제
- `_batch_upsert()`: 500개씩 Supabase 배치 upsert 헬퍼

**backend/scripts/daily_refresh.py** 확장
- `--phase universe`: ticker_universe 전체 갱신 (주 1회)
- `--phase snapshot`: 전체 시장 스냅샷 수집 + 정리
- `--market KR|US|all`: 대상 시장 선택
- `--date YYYYMMDD`: 날짜 지정 (snapshot phase)
- 기존 fundamentals/history 수집은 `--phase fundamentals` (기본값)로 유지

### 백엔드 API (Phase 9-B)

**backend/routers/market_full.py** 신규
- `GET /api/market/full`: 전체종목 테이블 (market/sector 필터, sort, 페이지네이션)
  - market_snapshot(최신 날짜) + ticker_universe 2-query 전략 (Python merge)
  - 5분 TtlCache
- `GET /api/market/full/search`: 종목명/심볼 ILIKE 검색 (최대 50건)
- 테이블 비어있을 때 빈 배열 반환 (graceful)

**backend/main.py**: market_full 라우터 등록 (`/api/market`)

### 프론트엔드 (Phase 9-C)

**src/lib/apiClient.ts**
- `MarketStock`, `MarketFullResponse`, `MarketSearchResponse` 타입 추가
- `fetchMarketFull(params)`, `fetchMarketSearch(q)` 함수

**src/hooks/useMarketFull.ts**
- `useQuery` 페이지네이션, staleTime 5분
- `placeholderData` — 페이지 전환 시 깜빡임 방지

**src/components/ProMarketFilter.tsx**
- 시장(전체/KR/US) + 정렬(시총/변동%/PER/이름) 필터 버튼
- active/inactive 상태 스타일링

**src/components/ProMarketList.tsx**
- 전체종목 테이블 (ProAllTickers 대체)
- 검색바 + ProMarketFilter 연동
- 컬럼: 종목명, 심볼, 시장 배지, 종가, 변동%(text-gain/loss), 시총(B/T 단위), PER, 섹터
- 페이지네이션 (prev/next, 1-100/N개 표시)
- 빈 상태: "시장 데이터 수집 중..." 메시지

**src/pages/ProDashboard.tsx**
- 개요 탭: ProAllTickers → ProMarketList 교체
