# 개발일지: 전역 폰트 일관성 확보 및 체급 상향

작성일: 2026-03-11

## 해결하고자 한 문제
- **페이지 간 폰트 불균형**: 홈 화면(`Index.tsx`)은 큰 폰트로 가독성이 확보된 반면, 관심종목, 포트폴리오, 알림 등 다른 페이지들은 `text-sm` 위주의 작은 서체를 사용하여 이질감이 느껴지고 가독성이 떨어지는 문제.

## 해결된 내용
- **주요 페이지 폰트 상향 조정**: `Watchlist.tsx`, `Portfolio.tsx`, `Alerts.tsx`의 텍스트 클래스를 전반적으로 1단계씩 상향 (`text-xs` -> `text-sm`, `text-sm` -> `text-base`, `text-base` -> `text-lg/xl`).
- **테이블 및 리스트 가독성 개선**: 
  - `PortfolioTable.tsx`의 데이터 수치와 헤더 폰트 크기 상향.
  - 리스트 아이템의 종목명과 가격 정보를 `text-lg` 테급으로 상향하여 시인성 확보.
- **UI 일관성**: 헤더의 서비스명(AntGravity)과 버튼 서체를 전역적으로 통일하여 앱 전체에서 일관된 시각적 경험을 제공.

## 결과
- 모든 페이지가 홈 화면과 동일한 수준의 시원한 가독성을 제공하며, 브랜드 아이덴티티가 더욱 견고해짐.
