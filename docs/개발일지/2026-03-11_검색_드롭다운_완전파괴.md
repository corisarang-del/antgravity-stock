# 개발일지: 검색 드롭다운 잔상 문제 최종 해결 (특단의 조치)

작성일: 2026-03-11

## 해결하고자 한 문제
- **드롭다운 미제거 및 겹침**: 종목 선택 후에도 드롭다운 목록이 남아 분석 리포트와 겹치는 문제. 사용자는 마우스 클릭 여부와 상관없이 '검색 액션' 발생 시 즉시 사라지기를 원함.

## 해결된 내용
- **물리적 데이터 파괴 (Results([]) )**: 단순히 `showDropdown` 플래그만 끄는 것이 아니라, 드롭다운이 렌더링할 데이터 원천인 `results` 배열을 즉시 빈 배열로 만듦. 이를 통해 애니메이션 지연과 상관없이 리스트 자체가 DOM에서 삭제됨.
- **포커스 강제 해제 (Blur)**: `inputRef.current?.blur()`를 호출하여 검색창의 포커스를 즉시 해제함으로써, 포커스 상태로 인해 드롭다운이 다시 열리는 시나리오를 방지함.
- **Enter 키 핸들러 완성**: `handleKeyDown`을 정의하여 엔터 입력 시 첫 번째 종목이 지연 없이 진단되도록 함.
- **onMouseDown 적용**: `onMouseDown`을 사용하여 클릭 시 발생하는 블러 이벤트를 선점하고 가장 빠른 타이밍에 UI를 닫음.

## 결과
- 엔터를 치거나 리스트를 터치/클릭하는 즉시 목록이 증발하며 AI 분석 리포트가 선명하게 노출됨.
