# 2026-03-11 개발일지: 폰트 및 캐릭터 스타일 변경

## 작성시각
2026-03-11T23:55:00+09:00

## 해결하고자 한 문제
사용자가 업로드한 레트로 빈티지 애니메이션 스타일의 이미지(개미 더듬이를 한 캐릭터)와 어울리도록 앱 전반의 캐릭터 이미지, 로고 텍스트 폰트, 그리고 배경 색상을 일관되게 수정하고자 함.

## 해결된 것
- `Playfair Display` 세리프 폰트를 `index.css`에 추가 및 `.font-logo` 유틸리티 클래스 생성
- 배경색을 따뜻한 크림색(`hsl(45, 45%, 96%)`)으로, 메인 테마색상(primary)을 빈티지 아쿠아/청록색(`hsl(185, 65%, 38%)`)으로 전반적인 색상 시스템 수정
- AppShell, AuthModal, PricingModal 등 로고 텍스트가 들어가는 부분에 `font-logo italic` 적용
- 새로운 캐릭터 이미지(`ant_character.png`) 생성 및 적용 (assets 폴더에 덮어쓰기 완료)

## 안된 것
- 업로드된 원본 이미지를 직접 추출하여 적용하는 것은 시스템 권한 상 제한되어 AI 생성물로 대체하여 덮어씀. (추가적으로 사용자가 원본 파일을 직접 assets에 붙여넣기 할 수 있음)
