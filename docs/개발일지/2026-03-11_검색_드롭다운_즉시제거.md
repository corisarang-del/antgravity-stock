# 개발일지: 검색 드롭다운 즉각 제거 및 엔터 핸들링

작성일: 2026-03-11

## 해결하고자 한 문제
- **드롭다운 잔상 고착**: 종목 선택 후나 검색 완료 시점에 드롭다운이 사라지지 않고 화면에 남아 분석 결과와 겹치는 문제. 사용자는 마우스 클릭 없이도(엔터 등) 즉시 사라지기를 원함.

## 해결된 내용
- **엔터 키 지원**: `onKeyDown` 핸들러를 추가하여 사용자가 검색어 입력 후 엔터를 누르면 첫 번째 검색 결과가 자동으로 선택되도록 함.
- **물리적 데이터 파괴**: 종목이 선택되는 즉시 `setResults([])`를 호출하여 드롭다운이 참조하는 데이터 배열 자체를 비움. 데이터가 없으므로 드롭다운은 즉시 파괴됨.
- **포커스 강제 해제**: 선택 완료 시 `blur()`를 호출하여 입력창의 포커스를 해제함으로써 모바일 키보드나 포커스 기반의 드롭다운 재출력을 방지함.

## 결과
- 엔터를 치거나 종목을 클릭하는 즉시 목록이 증발하며 분석 리포트만 깔끔게 노출됨.
