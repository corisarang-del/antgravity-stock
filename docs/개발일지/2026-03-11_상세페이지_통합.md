# 개발일지 - 2026-03-11 (상세페이지 홈 화면 통합)

- **작성시각**: 2026-03-11 21:28
- **요구사항**: 분리된 종목 상세 페이지(`/stock/:symbol`)를 없애고, 홈 화면(`Index.tsx`) 하나에서 여러 종목들의 상세 정보가 탭 구성을 통해 즉각적으로 교체되는 "통합형 싱글 페이지" 구조를 구현.

## 변경점
- `Index.tsx`:
  - `StockDetail.tsx`에 분산되어 있던 `차트`, `재무제표`, `뉴스`, `애널리스트 목표가` 탭 뷰를 모두 이식.
  - 기존의 넓은 패딩, 카드 배경 등 "디자인 규칙"을 준수하여 탭 메뉴와 상세 컨텐츠를 중앙 메인 영역에 위화감 없이 배치.
  - `location.state?.symbol` 값을 받아 `STOCKS` 데이터를 갈아 끼우는 상태 관리(state) 패턴을 유지하여 라우팅 부하 없이 빠른 종목 전환 달성.
  
- 라우팅 정리:
  - `App.tsx`에서 `/stock/:symbol` 라우트를 제거.
  - `Watchlist.tsx`, `PortfolioTable.tsx`, `StockList.tsx`, `StockDiagnose.tsx` 등 모든 컴포넌트의 외부 링크를 `/home`으로 돌리고 내부에 `state: { symbol }` 값을 넘기도록 코드 일괄 수정.
  - 불필요해진 `StockDetail.tsx`, `StockHeader.tsx` 내부 '상세 보기' 버튼 등 잔여 코드 삭제.

## 성과
별도의 페이지 로딩 없이 하나의 대시보드 안에서 모든 종류의 개별 주식 정보를 딥-다이브할 수 있게 되어, 강력한 투자 분석 플랫폼으로서의 UX를 고도화함.
