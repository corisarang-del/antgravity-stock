# 개발일지: 검색 드롭다운 겹침 현상 최종 해결

작성일: 2026-03-11

## 해결하고자 한 문제
- **드롭다운 미제거 및 겹침**: 종목 선택(클릭) 후에도 검색 결과 목록(드롭다운)이 사라지지 않고 하단의 분석 결과 카드와 겹쳐서 보이는 문제.

## 해결된 내용
- **onMouseDown 핸들러 도입**: 기존 `onClick` 대신 `onMouseDown`을 사용하고 `e.preventDefault()`를 호출하여, 입력창의 포커스 변화가 발생하기 전에 종목 선택 로직을 실행하고 드롭다운을 즉시 닫음.
- **결과 데이터 강제 초기화**: 종목 선택 시 `setResults([])`를 호출하여 검색 결과 배열 자체를 비움으로써, `onFocus` 등에 의해 드롭다운이 다시 열릴 여지를 차단함.
- **상태 제어 강화**: 드롭다운 노출 플래그(`setShowDropdown(false)`)를 최우선적으로 처리하여 애니메이션과 상관없이 즉각적인 시각적 피드백 제공.

## 결과
- 종목 선택 시 목록이 즉시 사라지고 AI 분석 리포트만 깔끔하게 노출됨.
