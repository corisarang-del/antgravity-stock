# 개발일지: 검색 선택 후 드롭다운 잔상 완벽 제거

작성일: 2026-03-11

## 해결하고자 한 문제
- **드롭다운 재노출 문제**: 종목을 선택하면 입력창에 이름이 들어가는데, 이 때 `query` 상태 변화가 감지되어 `useEffect`가 다시 실행되면서 드롭다운이 다시 열리는 현상. 결과적으로 분석 결과 카드 위에 드롭다운이 계속 떠 있어 화면을 가리게 됨.

## 해결된 내용
- **프로그래밍 방식 변경 감지**: `isProgrammaticChange` 레퍼런스(Ref)를 추가하여, 종목 선택으로 인한 입력값 변경 시에는 드롭다운을 열지 않도록 제어 로직 구현.
- **로직 정교화**: 
    1. 사용자가 직접 타이핑할 때만 드롭다운이 열리고 이전 결과가 초기화됨.
    2. 종목 리스트에서 항목을 클릭하여 선택 완료 시에는 드롭다운이 강제로 닫힌 상태 유지.

## 결과
- 처음 검색이나 재검색 시 모두 종목 선택 직후 드롭다운이 즉시 사라지고 AI 분석 결과만 깔끔하게 노출됨.
