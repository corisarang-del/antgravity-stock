# 개발일지: 검색 드롭다운 제어 로직 전면 개편

작성일: 2026-03-11

## 해결하고자 한 문제
- **드롭다운 지속 노출**: 종목 선택 후 `setQuery`에 의해 상태가 변할 때 `useEffect`가 사이드 이펙트로 드롭다운을 다시 열어버리는 문제. 명시적으로 닫아도 `useEffect`의 의존성 때문에 재발함.

## 해결된 내용
- **상태 기반 자동화 제거**: `useEffect`에 의존하던 검색 로직을 제거하고, `onChange` 핸들러(`handleSearch`)에서 직접 동기적으로 검색 결과와 드롭다운 노출을 제어하도록 변경.
- **명시적 제어**: 
    1. 사용자가 직접 입력할 때만 `handleSearch`가 실행되어 드롭다운이 열림.
    2. 종목 선택 시 실행되는 `diagnose` 함수는 `setQuery`만 호출하고 검색 로직을 거치지 않으므로 드롭다운이 절대 다시 열리지 않음.
- **결과**: 선택 즉시 목록이 사라지고 깨끗한 분석 결과 카드만 노출되는 것을 보장.
