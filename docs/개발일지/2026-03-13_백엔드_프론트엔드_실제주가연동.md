# 2026-03-13 백엔드-프론트엔드 실제 주가 연동

## 작성 시각
2026-03-13

## 해결하고자 한 문제
프론트엔드가 `src/data/stockData.ts`의 Mock 데이터를 사용하고 있어 실제 주가 데이터와 연결이 안 된 상태였다.
백엔드(FastAPI + AntLSTM + yfinance + Gemini)는 이미 완성되어 있었으나 두 레이어가 연결되지 않은 상태.

## 구현 내용

### 완료된 것

**Step 1 - Vite 프록시 설정** (`vite.config.ts`)
- `/api` → `http://localhost:8000` 프록시 이미 설정됨 (CORS 우회)
- lovable-tagger 잔재 제거됨

**Step 2 - DART API 연동** (`backend/routers/tips.py`, `backend/core/config.py`)
- `DART_API_KEY` 환경변수 설정
- DART `irdsSttus.json` 엔드포인트 실제 호출 구현
- 24시간 TTL in-memory 캐시(`_TtlCache`) 구현
- 키 없을 시 하드코딩 fallback 데이터 반환

**Step 3 - 프론트엔드 API 클라이언트** (`src/lib/apiClient.ts`)
- 심볼 변환 규칙: 6자리 숫자 → `.KS` suffix (KR 종목), 그 외 그대로 (US 종목)
- 타입 정의: `OhlcvRow`, `StockDetail`, `Prediction`, `StockBundle`, `MarketTickerItem`, `BackendIpoItem`
- API 함수: `fetchStockBundle`, `fetchMarketTicker`, `fetchIpoCalendar`, `fetchSentiment`, `fetchPrediction`
- 인증: Supabase 세션에서 `X-User-ID` 헤더 자동 주입

**Step 4 - TanStack Query 훅**
- `useStockBundle` (staleTime 5분)
- `useMarketTicker` (staleTime + refetchInterval 1분)
- `useIpoData` (staleTime 1시간)

**Step 5 - StockDetailPanel 실제 데이터 연동** (`src/components/StockDetailPanel.tsx`)
- `useStockBundle` 훅으로 OHLCV + LSTM 예측 fetch
- 로딩 중: animate-pulse skeleton 표시
- 에러 시: Mock 데이터 폴백
- OHLCV → 차트 데이터 변환 (`toChartData`)
- 현재가/등락률 마지막 2개 close 값으로 계산
- 예측 기반 signal 도출 (`calcSignal`)

**Step 6 - MarketOverview 실제 데이터 연동** (`src/components/MarketOverview.tsx`)
- `useMarketTicker` 훅 사용
- 실제 데이터 없을 시 INDICES Mock 폴백

**Step 7 - Tips 페이지 연동** (`src/pages/Tips.tsx`)
- `useIpoData` 훅으로 실제 IPO 데이터 fetch
- Loading skeleton 카드 표시
- DART 연동 성공/실패 상태 배지 표시 (Wifi/WifiOff 아이콘)
- 에러 시 샘플 데이터 폴백

  → 별도 태스크로 처리 필요

5. `/tips` 페이지 IPO 데이터 확인
