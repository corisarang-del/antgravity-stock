

# 개발일지: 전역 UI 보정 및 가독성 최종 강화

## 작성 시각: 2026-03-11 21:55

## 해결하고자 한 문제
1. **탭 UI 구분감 부족**: `AppShell` 내비게이션 탭들이 서로 겹쳐 보이거나 활성/비활성 구분이 모호함.
2. **티커 가독성 저하**: 상단 실시간 마켓 티커의 텍스트가 너무 작아 인지가 어려움.
3. **불필요한 내비게이션 노출**: `Diagnose.tsx`에 중복된 '홈으로' 버튼이 디자인 흐름을 방해함.

## 해결된 것
- `AppShell.tsx`:
  - 탭 컨테이너의 간격(`gap`)을 확대하고 배경 투명도를 조정하여 버튼 형태를 명확히 함.
  - 비활성 탭에 호버 시 `bg-background/50` 배경을 추가하여 조작 가능함을 강조.
- `MarketOverview.tsx`:
  - `MarketTicker` 내의 지수 이름, 수치, 등락폭 폰트 체급을 전체적으로 상향 조정.
- `Diagnose.tsx`:
  - 상단에 배치되었던 '홈으로' 버튼 섹션을 삭제하여 히어로 섹션에 집중하도록 개선.

## 남은 과제
- 없음. 모든 페이지에 대한 가독성 향상 및 사용자 피드백 반영 완료.
