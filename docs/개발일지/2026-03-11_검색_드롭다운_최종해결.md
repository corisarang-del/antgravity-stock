# 개발일지: 검색 드롭다운 잔상 문제 최종 해결 (강력 조치)

작성일: 2026-03-11

## 해결하고자 한 문제
- **드롭다운 미제거 및 겹침**: 종목 선택 후에도 목록이 남아 분석 리포트를 가리는 문제. 특정 브라우저나 환경에서 클릭 이벤트가 지연되거나 다른 상태 변화와 겹쳐 발생하는 것으로 판단됨.

## 해결된 내용
- **onMouseDown 핸들러 적용**: 클릭보다 앞서 발생하는 `onMouseDown` 단계에서 `e.preventDefault()`를 통해 포커스 아웃이나 블러(blur)로 인한 오작동을 원천 차단하고 즉각적인 선택 처리를 수행함.
- **결과 목록 즉시 파괴**: `diagnose` 함수 내에서 `setResults([])`를 호출하여 렌더링할 목록 자체를 즉시 비우도록 함.
- **드롭다운 노출 방지 추가**: 선택된 상태에서는 드롭다운이 열리지 않도록 `setShowDropdown(false)`를 명시적으로 호출.

## 결과
- 종목 선택과 동시에 목록이 증발하며, AI 분석 결과 카드만 선명하게 노출됨을 보장함.
