# 개발일지 - 2026-03-11 (Stockray 플로우 벤치마킹 반영)

- **작성시각**: 2026-03-11 20:50
- **해결하고자 한 문제**: 종목 검색 후 바로 홈화면으로 넘어가는 대신, Stockray 사이트처럼 진단 점수를 결과 페이지(랜딩 화면 내)에서 렌더링 한 뒤, 상세 조회 트리거를 통해 넘어가게 하는 라우팅 플로우 복구.

## 해결된 것
- `Diagnose.tsx`의 진단 로딩 종료 시 라우팅 스킵 기능을 제거하고 다시 결과 카드가 렌더링되도록 수정.
- 결과 카드의 CTA 영역 (상세 분석 보기) 클릭 시 `navigate("/home")`로 이동하면서 `state: { symbol }`을 넘겨주도록 변경.
- `Index.tsx`에서 마운트 시 받은 `state.symbol` 기반으로 대시보드 선택 종목(`selectedSymbol`)을 초기화해, 검색 종목이 즉시 대시보드에 연동되게 수정.

## 비고
- 검색 즉시 차트 대시보드로 넘어가지 않고 인공지능 분석과 등급/점수에 주목시키는 랜딩 플로우가 사용자 경험 향상에 효과적임을 벤치마킹을 통해 파악함.
