## 해결된 것

### Phase 4: 꿀팁 페이지 한국 개장일 (`feature/tips-trading-calendar`)

- `korea-business-day` npm 패키지 도입 (2022~2027 개장일 데이터)
- `TradingStatusBanner.tsx`: 오늘 개장 여부 + 다음 거래일 카운트다운
- `KoreanTradingCalendar.tsx`: 이달 거래일/휴장일/공휴일 달력 (색상 구분)
- `Tips.tsx`: 기존 IPO 섹션 위에 개장일 섹션 추가
- 클라이언트 순수 계산 — 서버 불필요, 타임존 독립적

### Phase 1~3: Pro 대시보드 (`feature/pro-dashboard`)

**백엔드:**
- `fundamentals_service.py`: KR → dartlab, US → yfinance 재무지표 통합
- Investment Score 5카테고리 알고리즘 (Quality 25 / Growth 20 / Strength 15 / Cash 15 / Valuation 25 = 100점)
- `history_service.py`: 5개년 연간 재무 히스토리
- `screener_service.py`: 11개 전략 필터 (워런버핏, 피터린치, 모멘텀 등) AND/OR 조합
- `sectors_service.py`: KRX API + yfinance 섹터 분류, 5분 TTL
- `dividends.py`: yfinance 배당 캘린더, 24시간 TTL
- 신규 엔드포인트 5종 등록

**프론트엔드:**
- `apiClient.ts` Pro 타입 12종 + 함수 5종 추가
- React Query 훅 4종 (useFundamentals, useScreener, useSectors, useDividendCalendar)
- 컴포넌트 8종 (InvestmentScoreCard, FundamentalsGrid, AiScreener, SectorHeatmap, HistoricalTable, DividendCalendar, ProTopRanking, DividendCalendar)
- `/pro` 라우트 + Pro 게이팅 (미구독자 업그레이드 유도)

## 해결 안 된 것 / 남은 작업

- dartlab 패키지가 `pip install dartlab[all]`로 설치 필요 (requirements.txt에 명시됨)
- KRX API는 외부 방화벽 환경에서 타임아웃 가능 → yfinance 폴백 있음
- 두 브랜치 PR 머지 (Phase 5) 미완료
- /pro 페이지 실제 브라우저 동작 확인 필요

## 기술적 결정 사항

| 결정 | 이유 |
|------|------|
| dartlab (KR) + yfinance (US) 혼용 | dartlab은 DART 정규화 재무 제공, yfinance는 US 재무 완전 지원 |
| korea-business-day 프론트엔드만 | 개장일은 클라이언트 계산으로 충분, 서버 불필요 |
| TtlCache 인메모리 캐시 | DB 불필요, 개인정보 저장 없음, 빠른 응답 |
| Recharts Treemap 재사용 | 기존 설치된 패키지 활용, 추가 설치 불필요 |
| Investment Score 100점 만점 | 5카테고리 가중치로 직관적 그레이드(S/A/B/C/D) |
