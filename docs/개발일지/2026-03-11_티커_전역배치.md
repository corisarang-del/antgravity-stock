# 개발일지 - 2026-03-11 (글로벌 증시 티커 전역 노출 및 리디자인)

- **작성시각**: 2026-03-11 21:15
- **해결하고자 한 문제**: 사용자가 추가로 제시한 레퍼런스 이미지(우상단 넓은 형태의 지표 정보)를 바탕으로, 대시보드 안에서만 보이던 시장 티커를 애플리케이션의 "모든 페이지 상단"에 고정되도록 `AppShell` 렌더링 조건을 변경하고, 시각적 디자인 역시 래퍼런스에 가깝게 개편.

## 해결된 것
- `AppShell.tsx`: 라우터 뷰들을 감싸는 메인 셸에서 `hideTicker` props 처리 로직을 완전히 삭제하여, 랜딩(`/`) 화면을 비롯한 모든 페이지의 최상단 헤더 바로 밑에서 `<MarketTicker />` 컴포넌트가 항상 흘러가도록 배치를 변경.
- `MarketOverview.tsx` 내부 티커 컴포넌트:
  - 기존의 반투명 회색 배경(`bg-secondary/40`)과 위아래 넓은 패딩(`py-2`)을 `bg-background py-1.5`로 변경해 윗 헤더와 위화감 없이 통일감을 줌.
  - 지수 명칭(S&P 500 등)은 `text-[11px] font-semibold text-muted-foreground uppercase`로 처리하고, 현재 지수를 `text-[13px] font-bold text-foreground`로 키워 직관성을 대폭 향상시킴.
  - 변동률 표시 역시 `증감 화살표 + 기호 (+/-) + 퍼센티지` 형태로 묶어 가시성을 높임.

## 비고
- 페이지 이동(렌더링)에 관계 없이 최상단에 증시 티커가 고정 렌더링되게 만듦으로써 금융 플랫폼 특유의 정보 전달력과 전문적인 분위기를 모든 라우트에서 제공함.
