# 2026-03-13 상세 페이지 인라인 통합

## 작성 시각
2026-03-13

## 해결하고자 한 문제

Diagnose(`/`) → "상세 분석 보기" → `/home` 이동 후,
`/home` 내 StockHeader의 "상세 분석" 버튼을 누르면 `/stock/000660` 같은 별도 URL 페이지로 이동하는 이중 탐색 문제.

- 사용자 입장에서 같은 내용을 두 번 거쳐야 하는 UX 불편
- 종목마다 별도 페이지를 만들지 않고, 공통 컴포넌트에 데이터만 바뀌는 구조 부재

## 변경 파일

### `src/components/StockDetailPanel.tsx` (신규)
- `StockDetail.tsx`의 핵심 UI를 재사용 가능한 컴포넌트로 추출
- `symbol: string` prop 하나만 받아 해당 종목 데이터 조회 후 렌더링
- 구성:
  - 종목 히어로 섹션 (symbol, name, sector, price, changePct, signal 배지)
  - 탭 바: 차트 / 재무제표 / 뉴스 / 목표가
  - 우측 AI 분석 패널 (`PredictionPanel`)
- 모듈 레벨 `STOCK_MAP = new Map(...)` 으로 O(1) 조회
- 접근성: 탭 버튼 `focus-visible:ring-2`, 아이콘 `aria-hidden="true"`, 수치 `tabular-nums`

### `src/pages/Index.tsx` (`/home`)
- 기존 StockHeader + StockChart + PredictionPanel 레이아웃 전면 교체
- `StockDetailPanel` 단일 컴포넌트 사용
- AI 진단 배너 제거 (Diagnose → Home 플로우로 진입하므로 불필요)
- `location.state?.symbol`로 선택 종목 초기화 유지

### `src/pages/StockDetail.tsx` (`/stock/:symbol`)
- 내부 로직 전부 `StockDetailPanel`로 교체
- 페이지 쉘(헤더 + MarketTicker)만 유지 — 직접 URL 접근 시에도 동일 UI 제공
- 뒤로가기 버튼: `navigate("/")` → `navigate("/home")` 수정
- 불필요한 state/데이터 조회 코드 제거 (StockDetailPanel이 자체적으로 처리)

### `src/components/StockHeader.tsx`
- `navigate('/stock/${symbol}')` ExternalLink 버튼 제거
- `useNavigate`, `ExternalLink` import 제거
- StockHeader는 독립 컴포넌트로 유지 (다른 곳에서 재사용 가능)
