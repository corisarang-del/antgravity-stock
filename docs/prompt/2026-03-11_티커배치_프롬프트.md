# 프롬프트 로그 - 2026-03-11 (글로벌 증시 티커 전역 고정 배치)

- **작성시각**: 2026-03-11 21:15
- **태스크**: 새로운 스크린샷 래퍼런스에 맞춰 MarketTicker를 AppShell 내부에서 항시 노출시키고 컴포넌트 뷰 사이즈 최적화.

## 사용된 명령 및 분석 흐름
1. 이미지 레이아웃 파악: 헤더(로고, 로그인) 메뉴 라인과 맞붙은 채로 길게 가로로 흘러가는 주가 흐름(마퀴 애니메이션) 영역 확인.
2. `AppShell.tsx`에서 랜딩 페이지(`/`) 시 티커 스크롤바가 숨김(`hideTicker=true`) 처리되는 기존 제약조건 확인.
3. 해당 조건을 과감히 들어내어 모든 라우트(Home, 진단, 설정 등)에 통과되도록 레이아웃 컴포넌트 개편.
4. `MarketOverview.tsx` 내의 MarketTicker 요소의 텍스트 크기와 굵기를 변경(지수명 vs 수치 대비 강화).
5. 롤백된 기존의 대화형 / 카드형 UI 태스크와 별개로, '항시 노출형 인포그래픽 바'로서의 래퍼런스 방향성을 잡아줌.
