- 모든 페이지에 홈 화면 수준의 폰트 크기 적용.
- `AppShell` 탭들이 겹쳐 보이지 않게 구분감 강화.

## 주요 수정 내용 및 프롬프트 전략
1. **모든 페이지 폰트 상향**: `Diagnose`, `Portfolio`, `Watchlist`, `Alerts` 등 주요 페이지와 그 하위 컴포넌트(`StockDiagnose`, `PortfolioTable` 등)에서 `text-xs` -> `text-sm`, `text-sm` -> `text-base` 위주로 체급을 올리는 `multi_replace_file_content` 사용.
2. **탭 구분감 개선**: `AppShell.tsx`에서 `gap`을 `1`에서 `2`로 늘리고, 비활성 상태의 `motion.div`에 호버 배경색을 추가하여 독립된 버튼임을 명시.
3. **티커 가독성**: `MarketOverview.tsx`의 내부 폰트들을 12~14% 가량 확대하여 시인성 확보.
4. **불필요 요소 제거**: `grep_search`로 '홈으로' 텍스트를 찾아 해당 코드 블록을 안전하게 삭제.

## 결과 및 시사점
- 전역적인 디자인 일관성을 유지하면서도 '크고 명확한' UI를 선호하는 사용자의 의도를 우선적으로 반영함.
- `AppShell`과 같은 공통 레이아웃 수정 시 모바일 뷰와의 관계를 고려하여 `text-xs` 정도의 마지노선을 지킴.
