## AI의 접근 방식

1. `StockDetail.tsx` 전체 구조 분석 (탭/히어로/AI패널)
2. `StockHeader.tsx` 에서 `navigate('/stock/:symbol')` 버튼 확인 — 이중 탐색 원인 파악
3. `StockDetailPanel.tsx` 공통 컴포넌트로 추출
4. `Index.tsx` 단순화 — `StockDetailPanel` 직접 렌더링
5. `StockDetail.tsx` 리팩토링 — `StockDetailPanel` 재사용
6. `StockHeader.tsx` 네비게이션 버튼 제거
7. `tsc --noEmit` + `pnpm build` 검증

## 해결 핵심

- 이중 탐색의 원인: `StockHeader` 내부에 `navigate('/stock/${symbol}')` 버튼이 존재
