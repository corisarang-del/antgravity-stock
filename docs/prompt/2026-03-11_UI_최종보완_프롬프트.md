# 프롬프트: UI 충돌 해결 및 브랜딩 정리

## 해결하고자 한 문제
사용자가 보고한 시각적 충돌(겹침) 문제와 잔여 브랜드 요소를 완벽히 제거.

## 사용한 전략
1. **CSS 레이아웃 수정 (AppShell)**: `header`와 `ticker`의 관계를 `absolute/sticky` 중첩이 아닌 단일 `sticky` 부모 아래에 두어 레이아웃 안정성 확보.
2. **UI 레이어링 최적화**: 검색 드롭다운에 `z-[60]` 및 `shadow-2xl`을 적용하여 시각적 깊이감을 부여하고 하단 요소와의 구분을 명확히 함.
3. **메타데이터 정제**: `index.html`을 분석하여 외부 브랜드 링크를 자사 리소스로 교체.

## 해결된 것
- 상단 티커 가림 현상 해결.
- 검색 결과 드롭다운 시인성 개선.
- 파비콘 및 OG 메타데이터 자사화.

- 없음 (지속적인 모니터링 필요).
